# MiniProxy

A client-side Fabric mod for routing Minecraft server connections through a SOCKS5 proxy.

## Features

- Save multiple SOCKS5 proxies (host, port, and optional username/password)
- Switch proxies directly from the multiplayer screen
- One-click toggle back to a direct connection

## Usage

1. Open Multiplayer and click Proxy in the top-right corner.
2. Click Add, enter your proxy host and port, and click Save.
3. Select your proxy and click Use Proxy.
4. Join any server as normal. Your connection will go through the selected proxy.
5. To disable it, select No proxy to return to a direct connection.
